Export options

  • Name, SKU, URL, price, stock, descriptions, images and other available fields.
  • Filters by price, stock, status, category, manufacturer and modification date.
  • CSV, XML, XLSX and Excel HTML (.xls). Google Merchant, Meta and YML are beta feeds: validate before import.
  • OpenCart: data language, storefront and separate option values. No option combinations. Other CMS export base products; Simpla uses the first variant.

Access and export

Access key, CSRF checks, a 15-minute IP login limit and session expiry. Optional IP allowlist in CMS builds.

The complete file is prepared on temporary disk before download. Preparation errors are shown without sending a partial catalog.

Adapters and scope

OpenCart / ocStore, WooCommerce, PrestaShop, 1C-Bitrix, CS-Cart, Magento 2, Shopware 6, Webasyst, MODX miniShop2, VirtueMart, HikaShop, JoomShopping, Simpla / OkayCMS.

Cloud: Shopify, BigCommerce, Wix, Prom.ua, JSON API / Horoshop.

Adapters depend on CMS versions and configuration. Check prices, URLs and stock against your store. Cloud adapters and beta feeds have not been verified against your account. Horoshop needs a compatible JSON endpoint. Generic XML is not a Prom/Rozetka import feed.

Install and export

  1. Download the build for your PHP version.
  2. Set a long, unique access key at the top of the PHP file. 
    // nyaaxport.php / nyaaxport_56.php
const NYAAXPORT_ACCESS_KEY = 'CHANGE-ME-NOW';
// Replace the value in the existing line:
const NYAAXPORT_ACCESS_KEY = 'your-own-long-random-secret';

// nyaaxport_cloud.php
const NYAAXPORT_CLOUD_KEY = 'your-own-long-random-secret';

    The CMS lines show before and after. Edit the existing line, do not add a second constant. Generate your own secret.

  3. Upload one PHP file to the store root and open over HTTPS. Cloud may be hosted separately.
  4. Enter the key, choose fields and filters, then export. In Cloud, select a provider and enter API credentials.
  5. Check the downloaded file and delete the exporter from the server after use.

Allow temporary disk space for the complete export. No Composer or additional server files required.
