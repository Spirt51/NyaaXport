# Галерея интерфейса и выравнивание фильтров

Три реальных этапа для каждого языка: витрина/фильтры, выбор полей/формата с успешной выгрузкой, вход по ключу. Снимки сделаны в Docker PHP 8.4 на локальном OpenCart SQL fixture с MariaDB 10.11. Демонстрационный каталог обозначен в подписи. Файлы обрезаны по интерфейсу, внешние поля страницы и донаты не входят в кадр.

Слайдер использует нативный горизонтальный скролл и scroll-snap. Стрелки переключают три кадра, высота подстраивается под текущий снимок. Клик открывает dialog с увеличением, кнопками вперёд/назад и режимом 100%. Escape, кнопка и фон закрывают окно. Нативный dialog удерживает фокус, после закрытия он возвращается на выбранный кадр. Без JavaScript изображения остаются ссылками на оригиналы.

Строки фильтров PHP выровнены через align-items:flex-end. На измерении нижние координаты поля даты и checkbox-label совпали: 600.4px для RU/UK/EN.

Направление сохранено из DESIGN.md: ENERGY 2 / RHYTHM 2 / MOTION 1. Слайдер добавлен по прямому запросу пользователя, без автопрокрутки. Снимки показывают работу экспортёра; 100% нужен для чтения текста на телефоне.

Delivery Gate: Hard Gate PASS (настоящие скриншоты, рабочие controls, native keyboard dialog); Purpose Gate PASS (галерея показывает последовательность, обрезка повышает читаемость); Liveliness PASS (существующие dials, без автодвижения); Craftsmanship PASS (мобильная высота по кадру, переводы и fallback-ссылки). Проверки галереи и релиза перечислены в сообщении о публикации.
