# Аудит NyaaXport, 15 октября 2026

Проверены index.html, три PHP-сборки и assets/ui-preview.html. Использованы antislop, antislop-ui и antislop-code, режим during, выбранный пользователем. Исходники не изменены. Hindsight недоступен (ECONNREFUSED).

## Функциональные находки

1. HIGH. Ограничение входов хранится только в сессии: новая cookie обнуляет счётчик. Cloud вообще не ограничивает попытки. Нет смены session ID после входа. nyaaxport.php:22–37,83–89; nyaaxport_56.php: те же участки; nyaaxport_cloud.php:9–19. Нужен независимый от cookie лимит с окном времени и обновление ID при входе.
2. HIGH. Заголовки скачивания и начало документа выводятся до исполнения генераторов. Ошибка SQL/API затем перехватывается и дописывает HTML интерфейса в выгрузку. nyaaxport.php:369–398,430–432; nyaaxport_cloud.php:55–59. Нужна подготовка результата до отправки файла либо отдельная обработка оборванного потока.
3. HIGH. Выбор витрины OpenCart меняет адрес и SEO JOIN, но не ограничивает товары через product_to_store. В файл попадают товары других витрин. nyaaxport.php:232–235,288; аналогично 5.6.
4. HIGH. Shopify запрашивает variants(first:100) без пагинации вариантов, поэтому варианты после сотого теряются. compareAtPrice записывается в special_price, хотя это сравнительная, а не акционная цена. nyaaxport_cloud.php:34–37. Нужны пагинация и единая семантика цен.
5. HIGH. Cloud принимает произвольный endpoint и домен, не проверяет HTTPS, локальные IP и разрешённые схемы cURL. Авторизованный пользователь может инициировать запрос из сети сервера и отправить токен произвольному хосту. nyaaxport_cloud.php:21–28,33–35,49. Нужны ограничения протокола/назначения с учётом DNS.
6. MEDIUM. Prom и Rozetka используют один общий XML с products/product; отдельных адаптеров нет. YML объявляет только USD, а offer может содержать другую валюту. nyaaxport.php:383–393. Нужна проверка каждого формата на реальном импорте; пока не обещать готовность всех фидов.
7. MEDIUM. Режим variants_only реализован только для OpenCart. WooCommerce выбирает только post_type=product; вариации не входят. Для Simpla GROUP BY p.id сводит варианты к одному, выбирая неагрегированные значения. nyaaxport.php:289,300,316–346. Описание поддержки вариантов должно уточнять платформы.

## UI и Antislop

8. HIGH, R-38. Картинки интерфейса подготовлены из отдельного макета assets/ui-preview.html, а не реального PHP-интерфейса. В макете переведены элементы, которые в PHP остаются английскими; показаны вымышленные количество товаров и статус диагностики. Подпись «пример» не объясняет различие. Использовать реальные снимки или явно назвать изображение концептом.
9. MEDIUM, R-05/R-09/R-17. Hero содержит декоративный терминал, число 12,450 без источника и pill над H1. На телефоне терминал стоит перед описанием и скачиванием. index.html:9,17,31,45. Заменить визуал продуктовым содержимым и убрать неподтверждённое число.
10. MEDIUM, R-03/R-25. Переключатели языков на сайте имеют высоту 34px вместо 44px. Белый текст на светлом конце градиента #a855f7 имеет контраст примерно 3.96:1, недостаточный для обычного текста. index.html:9. Увеличить зоны нажатия и затемнить фон CTA.
11. MEDIUM, C-4/R-26. В PHP нет обратной связи при неверном ключе до исчерпания попыток; в Cloud её нет вообще. Нет индикатора начавшейся выгрузки. nyaaxport.php:83–89,440; nyaaxport_cloud.php:18,59. Показывать результат входа и состояние экспорта.
12. MEDIUM, C-4. Локализация неполная: Filters, Search, Profile, Variants, Diagnostics и донаты не проходят через словарь. Cloud целиком с русским интерфейсом. nyaaxport.php:444–451; nyaaxport_cloud.php:59. Полные словари RU/UK/EN нужны для всех состояний.
13. MEDIUM, R-03. В PHP-сборках мобильный CSS превращает ячейки донатов в display:block; PayPal остаётся mailto. Сайт уже исправлен, сами приложения нет. nyaaxport.php:435,451; аналогично 5.6; nyaaxport_cloud.php:59.
14. LOW, R-32/C-4. Язык сайта показывается только классом active, без aria-pressed; все языковые статьи по умолчанию скрыты, а исключение localStorage оставит основной контент скрытым. index.html:9,61–68. Нужен доступный признак выбора и видимый HTML по умолчанию.

## Комментарии и поддерживаемость

15. LOW, antislop-code. Комментарии названий CMS в detectCms полезны для навигации и не требуют удаления. Заголовочный комментарий основной/5.6 сборки перечисляет только четыре CMS и устарел. Основная проблема поддержки находится в исполняемом коде: крупные однострочные SQL, CSS и HTML затрудняют ревью. Навык antislop-code разрешает править только комментарии, поэтому форматирование и рефакторинг требуют отдельной задачи.
