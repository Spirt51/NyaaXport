## Проверки

- PHP 5.6.40, 7.3, 7.4, 8.0, 8.1: регрессионные проверки проходят. Парсер дополнительно проверяет синтаксис PHP 5.6/7.0. Настоящий PHP 5.6 запускает страницу входа (с OpenSSL).
- Регрессии: поздний сбой не отдаёт заголовки/байты, XLSX открывается как ZIP, валюты YML, безопасные CSV-ячейки, unsafe API URLs/IPs, 101 вариант Shopify с дополнительной страницей.
- HTTP: новый session ID после входа, CSRF 422 без вложения, Cloud 422 без partial XML, восемь попыток с разными cookies блокируют девятую, выход удаляет авторизацию.
- Сайт: RU/UK/EN × light/dark × 320/375/768/1440px без горизонтального overflow; изображения загрузились. Кнопки языков >=44px, колонки донатов table-cell.
- Браузер: язык и тема переключаются; Tab даёт видимый focus. JS-disabled оставляет заголовок и три скачивания. При исключениях localStorage перевод продолжает работать.
- CMS-форма на локальной detection fixture: вход, фильтры, все/прайсовые поля, варианты, формат, раскрытие диагностики, ошибка экспорта, повторная доступность кнопки, тема и выход. Без драйвера БД намеренно проверен error path.
- Cloud-форма: выбор всех пяти платформ показывает соответствующие поля, остальные disabled/hidden.
- Ссылки платежей проверяются как назначения; денежные операции не выполнялись. Файлы релиза проверяются после публикации.

## Delivery Gate

- Hard Gate PASS: нет вымышленных метрик/отзывов/статусов, сайт и формы проверены на мобильных ширинах, действия дают результат или явную ошибку. Реальные внешние импорты не представлены как проверенные.
- Purpose Gate PASS: фиолетовый выделяет основное скачивание, моноширинный шрифт используется для кода/адресов, системный шрифт поддерживает три алфавита, границы отделяют инструкции. Декоративных terminal/glow/badge нет.
- Liveliness PASS: ENERGY 2 / RHYTHM 2 / MOTION 1; один главный CTA, разные композиции скачиваний, иллюстрации, текста и инструкции, без циклической анимации.
- Craftsmanship PASS: точные названия действий, видимые focus и состояния, обе темы, fallback без JavaScript. Остаточные ограничения адаптеров перечислены рядом с возможностями и в CHANGELOG.
- Code comments PASS: комментарии объясняют ограничения/назначение; декоративных баннеров и пооперационного пересказа нет. Изменения логики выполнены в рамках общего запроса пользователя, а не по полномочиям antislop-code.

Ограничение проверки: нет предоставленных действующих баз магазинов, API-токенов и кабинетов маркетплейсов. Фикстуры проверяют исправленные ветки, но не сертифицируют все схемы CMS.

## Дополнение: Docker и noindex

По уточнению пользователя выполнены проверки в Docker на PHP 5.6, 7.0, 7.4, 8.1, 8.4 и 8.5. Все регрессионные проверки проходят в read-only контейнерах с отдельной временной папкой и без сети. Исходники копируются в образ: настройка общего доступа диска D не требуется.

На MariaDB 10.11 проверен настоящий SQL OpenCart: отбор витрины, валюта, опции и пустая выборка. Найдено и исправлено отсутствие обратных кавычек вокруг колонки `ssl` в запросе витрины. На PHP 5.6 и 8.4 проверены HTTP-скачивания всех семи форматов, содержимое выбранной витрины, XLSX ZIP и ответ 422 при пустой выборке.

Все PHP-сборки отправляют X-Robots-Tag: noindex, nofollow и соответствующий HTML meta robots. Заголовок проверен и для скачиваемых файлов. Публичная страница проекта остаётся индексируемой.
